## 🔍 How to Find Your Manual

For the best results, search using the manufacturer, exact model and year whenever possible.

**Recommended search format:**

1. Manufacturer — for example, `Suzuki`
2. Model — for example, `GSX-R1000`
3. Model year — for example, `2020`
4. Document type — for example, `service manual` or `wiring diagram`

Try different variations if your first search does not return a result.

Examples:

- `Suzuki GSX-R1000 service manual`
- `Honda CBR600RR workshop manual`
- `Yamaha YZF-R1 repair manual`
- `Kawasaki Ninja ZX-6R wiring diagram`
- `BMW R 1250 GS service manual`
- `Ducati Monster owner's manual`
- `KTM 390 Duke workshop manual`
- `Honda PCX 125 service manual`
- `CFMoto 650MT repair manual`
- `Zero SR/F service manual`

**Tip:** Model names can differ by market, generation and year. Verify the exact model designation before using technical specifications or repair procedures.

## 🧰 Use Manuals Responsibly

Technical documentation can help with maintenance, troubleshooting and repairs, but the correct document matters.

Before starting work:

1. Confirm the make, model, year and market version of your vehicle.
2. Check that the manual applies to your exact model and engine configuration.
3. Follow the manufacturer's safety procedures and specifications.
4. Use the correct tools and torque values.
5. Consult a qualified technician when a repair involves safety-critical components or work beyond your training.

This repository is a discovery and indexing resource. Always verify the source, applicability and accuracy of the documentation you use.
